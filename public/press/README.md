# ListAI Pro — Press Kit

Everything here is safe to quote and is kept truthful to the shipped product.

- `one-liner.txt` — the 12-word version
- `short-description.txt` (50 words) · `medium-description.txt` (150) · `long-description.txt` (400)
- `founder-bio.md` — 1-line / 50-word / 150-word versions
- `brand-colors.txt` — palette
- `logos/` — logo marks (SVG)
- `product-screenshots/` — what to capture and when (filled at launch)
- `key-stats.json` — current numbers, updated at each release
- `notable-quotes.md` — user quotes (with consent) — empty until real users exist
- `press-coverage.md` — coverage log
- `contact.md` — how to reach the founder

Served at `/press/<filename>` on the product site.
